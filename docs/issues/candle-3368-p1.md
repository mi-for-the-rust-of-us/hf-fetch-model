**Update: the ecosystem now has a home, [MI for the Rust of Us](https://github.com/mi-for-the-rust-of-us), and 56 releases since [June 30th](https://github.com/huggingface/candle/discussions/3368#discussioncomment-17484983).**

The crates moved into a GitHub organization over the summer (the old `PCfVW/...` links redirect). It now holds six crates, all on crates.io, and a research note:

- **[candle-mi](https://github.com/mi-for-the-rust-of-us/candle-mi)** (0.1.17 → 0.2.2, 10 releases): training support behind a `training` feature (backbones that carry gradients, a checkpointable `AdamW`); `Intervention::PatchAt` for position-level activation patching; self-conditioning for `OthelloGpt`; the Figure-13 newline experiments.
- **[candle-fused-attn](https://github.com/mi-for-the-rust-of-us/candle-fused-attn)** (new, 0.4.0): fused fp32 scaled-dot-product attention for candle, FlashAttention-2 in plain fp32 CUDA, forward and backward, with a bit-reproducible backward: custom ops over stock candle 0.11, nothing to patch. candle-mi uses it behind its `fused-attn` feature.
- **[hf-fetch-model](https://github.com/mi-for-the-rust-of-us/hf-fetch-model)** (0.10.7 → 0.13.0, 14 releases): `inspect` now reads `.npz`, GGUF and `.pth` headers remotely over HTTP Range, as it already did `.safetensors`; `quants --fits` says which quant of a model fits a VRAM budget; `peek` shows small files without downloading; `du` names duplicated copies and `cache dedupe` reclaims them (154 GiB back on my Windows cache, no model deleted); `cache move` relocates a repo to another disk behind a link (159 GiB moved today).
- **[anamnesis](https://github.com/mi-for-the-rust-of-us/anamnesis)** (0.6.8 → 0.7.11, 13 releases): GGUF `NVFP4`, `Q1_0`, `Q2_0` and `F8_E4M3`, NVIDIA ModelOpt `NVFP4` safetensors, multi-threaded dequantisation, tighter parse limits, and a hardened release pipeline.
- **[hypomnesis](https://github.com/mi-for-the-rust-of-us/hypomnesis)** (0.2.4 → 0.2.15, 11 releases): its `hmn` tool (`hmn ps`, `hmn watch`) shows which process holds memory on which GPU, on Windows, Linux and macOS, now installs with `cargo install hypomnesis`, and got macOS sandbox handling from an outside contributor.
- **[vast-skopos](https://github.com/mi-for-the-rust-of-us/vast-skopos)** (new, 0.4.0): a read-only lookout over rented vast.ai GPU boxes: status, cost, credit, and what each GPU is actually doing. Not affiliated with vast.ai.
- **[parallel-commitment](https://github.com/mi-for-the-rust-of-us/parallel-commitment)**: a 4-page note on what parallel commitment costs a masked diffusion LM (0.95% when a 152-position span is committed in one pass, 99.56% one position at a time), built on candle-mi.

**Use.** Stars are few, but hf-fetch-model is pulled: a release that stays current for a few weeks reaches a few hundred downloads on crates.io (0.12.1: 457, 0.12.3: 347), each bringing anamnesis and hypomnesis along, where a release nobody uses gets 11 to 20 from mirrors. Much of it comes in bursts, so likely a few automated users rather than many people. candle-mi's own releases are still at that baseline.

**Back to candle.** `hf-fm inspect` keeps serving as evidence on candle issues (today on [#4018](https://github.com/huggingface/candle/issues/4018), and a reproduction on [#4031](https://github.com/huggingface/candle/issues/4031)); [#3944](https://github.com/huggingface/candle/pull/3944) was merged in September, and [#3628](https://github.com/huggingface/candle/pull/3628) (pickle-VM hardening) and [#4097](https://github.com/huggingface/candle/pull/4097) (`candle-core` 0.11.1 on Rust 1.91 to 1.93, x86_64) are open.
